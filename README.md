# Weather App ☀️🌧️

A React-powered weather application that allows users to search for a city and view real-time weather information. The app fetches live data from a weather 
API and displays current conditions such as temperature, weather description, and location details in a clean, responsive interface.

## Overview

This project focuses on consuming external APIs in a React application and managing asynchronous data with hooks. 
Users can search for weather conditions by city and receive instant feedback with dynamically updated UI components.

---

## The challenge

Users should be able to:

- Search for weather data by city name  
- View real-time weather information fetched from an external API  
- See temperature, weather conditions, and location details  
- Experience loading and error states when data is unavailable  
- Interact with a responsive and user-friendly interface  
- Understand API data flow and state management in React

## 🧠Key takeaways

This project reflects a strong understanding of React architecture and real-world development workflows:

1. Fetching Data from an API
Used the fetch API to retrieve real-time weather data and handled asynchronous operations using async/await.

3. Handling Side Effects with useEffect
Implemented the useEffect hook to trigger API calls when the component mounts or when user input changes.

5. State Management with Hooks
Managed multiple pieces of state using useState, including user input, fetched weather data, loading states, and errors.

6. Conditional Rendering
Displayed different UI elements based on the app’s state, such as loading indicators, error messages, or weather results.

5. Controlled Inputs
Created controlled form inputs for city search, keeping input values fully synced with React state.

6. Error Handling
Handled API errors gracefully by displaying user-friendly messages when a city is not found or data cannot be fetched.

7. Component Structure
Organized the app into reusable and readable components, improving maintainability and clarity.
